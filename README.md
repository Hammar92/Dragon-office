# 药厂生存记 · 临床开发部

## Demo v10.2 · Life Build, Relationship History & Coalition Governance

纯 HTML/CSS/JavaScript 的临床开发职场 Galgame / 生存叙事。

### 本版重点

- 18 章主线：Phase I → Phase II → EOP2 → Phase III → Pre-NDA / NDA
- 开局新增“捏人”：性别、学业背景、工作年限、专业能力、社交底色、个人魅力
- 新增玩家能力：专业、社交、魅力、项目管理、洞察
- 事件选项支持能力门槛；能力不足时可以看到但不能选择高阶选项
- 社交能力影响说服型互动，魅力影响 NPC 态度与关系收益倍率
- 关键项目经历 / 职业层级提升可获得成长点
- 新增“成长商店”：用成长点继续提升能力
- 当前所有初始点数、门槛、成长点产出与倍率均为占位值，完整事件设计完成后再统一模拟校准
- NPC 关系继续使用 Relation / Respect / Favor / Fear / Alignment
- 新增 Functional Cooperation：私人关系差，不代表项目必须合作失败
- 新增 Organizational Cohesion：衡量组织“能不能吵着把事做完”
- 新增 Political Debt：频繁依赖某一阵营会留下组织政治成本
- 新增组织治理工具：RACI、关键路径板、Decision Log、Pre-read + 决策会、Access Matrix
- 结构性阵营可重叠：创始核心圈、专业主义、执行推进、位置型权力、外部资源
- 苏苏会根据玩家性别与老板互动方式采用不同的隐藏判断策略
- 删除童欣；卫来改为苏苏；加入则韩（统计D）与杨杨（PMD）

### 当前人物机制原则

游戏不要求所有 NPC 彼此喜欢。高水平玩法是让互相有旧怨、专业冲突或私人矛盾的人，在清晰治理机制下继续推进项目。

例如：
- 肖恩 × 朱粽：私人低信任，但可通过 RACI 和留痕保持功能性合作
- 苏苏 × 杨杨：管理理念和私人警惕并存，但关键路径治理可以保持项目推进
- 二老板 × 肖恩：Micromanagement 与运营/质量边界冲突，可通过 Pre-read 降低摩擦
- 明夜 × 则韩：速度与经验错位，可形成“快速洞察 + 注册落地”的组合

### v10.1：人生履历、性格与情绪控制

- 开局捏人改为 6 个人生阶段：高中以前、大学、研究生/博士、入行0–3年、工作3–6年、工作6年+
- 每个阶段有独立时间点，玩家通过“把时间花在哪里”获得经历，而不是直接购买“北大毕业”等结果词条
- 经历组合自动拼出品质词条，使用普通 / 优秀 / 精良 / 史诗 / 传说体系
- 当前已接入示例词条：北大毕业、专业优秀、社交能力较强、优秀项目经理、组织型领导者、完整三期经验、从FIH做到NDA、精力旺盛、铁人、边界清晰、抗压能力强、内核稳定、高度自控、泰山崩于前而色不变、工作狂、聪明地偷懒、政治敏感、胜负欲强
- 新增管理能力、体能、心力韧性
- 新增隐藏人格轴：情绪稳定、边界感、冲突风格、控制倾向、成就驱动、人际信任
- 情绪控制由人格、洞察、心力、疲劳等动态派生；低Heart时，部分理性高阶选项可能因情绪失控被锁定
- 工作中的选择会让人格发生漂移，不再只有开局固定性格
- 体能会影响工作体力消耗和恢复；心力韧性会影响被否定、冲突和返工造成的Heart损耗
- 管理能力会直接强化RACI、Critical Path等组织治理工具，而不是只增加“项目进度”
- 成长商店已加入管理、体能和心力韧性升级
- 所有时间点、词条阈值、成长成本与倍率仍为 PLACEHOLDER，待事件设计完成后统一跑数值测试


### v10.2：扩展人生事件与情感经历

- 六个人生阶段事件池进一步扩展；新增事件覆盖学业、科研、演讲、实习、家庭支持、家庭压力、带团队、预算、危机管理、健康警报等方向
- 新增情感经历：初恋、稳定恋爱、异地关系、分手、背叛、长期单身、长期伴侣/婚姻、离婚与重建、边界模糊关系、伴侣支持等
- 同一阶段互斥的关系状态不能同时选择，避免明显矛盾的人生履历
- 情感经历会影响初始 Heart / Sanity / Morale / Career / Power / Reputation / Trust 等状态
- 情感经历同时影响隐藏人格：稳定性、边界感、默认信任、控制倾向、成就驱动等
- 新增关系类词条：被好好爱过、一个人也过得很好、关系里受过伤、把自己重新搭起来过、稳定后方、不轻易交付信任、会处理自己的情绪、长期照顾者、关系不是项目
- “稳定关系”不是纯Buff，“受过伤”也不是纯Debuff；不同经历形成不同的洞察、边界、信任和恢复方式
- 稳定后方会提供持续心力恢复；经历过重建的角色在低Heart状态下有额外恢复能力
- Builder现在直接预览人生经历对入职时各项基础状态的影响
- 本版所有数值继续使用 PLACEHOLDER，待人物、主线与事件池基本完成后统一平衡

## v12.0 — 分支事件网 / 99互斥成就 / 随机事件扩展

- 18章不再是单线顺序剧情：早期选择会累计为治理、迎合、权力、照顾四类行为倾向，并通过具体flag改变后续章节人物、问题和冲突。
- 关键分支包括：试用期资源冲突、钟时记忆改写、PV/PVP独立性、CRO责任邮件、MK主任直接联系、MK–N学术领地、口头承诺回流、会议文化、钟时Control Threat、老板私聊、权力线正式化、继任/影子组织、屠龙前夜等。
- 99个成就重做为33组三选一结果：18个主线事件组 + 15个随机事件组。每组单周目只能解锁一个结果，另外两个必须在后续周目走不同选择。
- 成就不再因为单纯数值达标或打开图鉴自动触发；必须做出对应选择并完成事件。
- 部分互斥成就奖励轮回点，继续支持开局返还和重选。
- 随机事件由8个扩展到15个，并加入按当前状态加权：例如CRO责任风险、PVP影子化、体力不足、MK–N关系升温等会提高相关事件出现概率。
- 新增随机事件：两份会议纪要、武总跨部门推动、贤人产品数据失忆、BD尽调前夜、苏苏治理边界、老板培养瑞冬、MK–N争大会席位等。

## v13.0 — 10个NPC随机事件 / 跨周目隐藏路线

- 随机事件由15个扩展到25个，新增事件均直接基于当前NPC性格，不再使用通用模板。
- 新事件包括：老板突然追问数字、二老板随机深挖、小圆把老板要求翻译成动作、邹婷工作坊补洞、一建文件权限、曹兰/贤人专家会分工、谷雨尽调安全问题、琳琳反对额外访视、林丹/明夜午饭情报、苏苏/武总医学判断边界。
- 新增跨周目隐藏路线系统。达成特定成就组合或特殊结局后，下一周目捏人界面会出现“前世经验”路线选择。
- 当前隐藏路线：留痕者、影子操盘手、织网者、龙之回声。每周目最多选择一条。
- 隐藏路线不会直接送结局；它们会在早期强制触发专属事件，让玩家利用上一周目的经验提前改变组织轨迹。
- 上一周目达到隐藏结局“屠龙”后，可解锁“龙之回声”。若新周目拒绝再次把权力集中到自己身上，并成功把项目做成，可进入跨周目隐藏结局《龙见过你，你没坐下》。
- 结局历史现在会保存在本地，用于后续周目路线解锁。
