# 结局插画 · v18.1

六幅独立画作由内置imagegen生成，主题对应结局特征，不是六张人物立绘。完整构图使用3:2比例；项目内webp为1200×800，约1.1MB总量。原始输出保留于生成目录，游戏仅引用仓库内稳定文件。

通用提示：单幅宽3:2的成熟职场黑色幽默叙事插画；油画与墨线的编辑插画质感，电影式明暗，石油蓝、旧象牙白、朱红；匿名职场人物与环境叙事，不用文字、字母、UI、水印、拼贴或血腥。政治讽刺通过物件和权责错位表达。

- empty-chair：深夜台灯照着空工位，冷咖啡和临床卷宗堆积，员工奖章摆在无人坐的椅子上，高管在磨砂玻璃后举杯。
- firefighter：疲惫员工跪在卷宗山下握着灭火器，巨大的金色灭火器奖杯居高临下，高管在奖杯基座为自己鼓掌，执行者与名位分离。
- dragon：高管坐在巨大办公桌前，审批笔连着所有文件、电话、座椅和假期行李，影子成为巨龙；改革者继承了旧瓶颈。
- team：会议桌成为跨越办公室裂隙的桥，五名同事分别托住支撑梁、传递卷宗，华丽王座闲置，一人仍能带行李离开。
- exit：普通员工抱纸箱走出办公楼，金色手铐留在衣架上，门外有人递晚饭，阴影里的会议仍围着微型自行车棚进行。
- audit：卷宗高塔缺了一块基础文件，钢笔投下牢栏般的影子，台灯、红章、真实来源文件和递交包并置；高管在磨砂玻璃后保持干净。

story/ending-review.js逐项指定主题和64项独立判词；每项判词与条件不同，同类结局共享寓言主题。达成时展示完整画面，解锁卷宗可回看。绘画是讽刺意象，不承担临床结果或现实人物照片的证明功能。
