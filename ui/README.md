# 办公工作台 · v18.1.0

剧情是工作台的主要区域。顶部只保留当前阶段、月度、情绪、职级与正在发生的会议/认定状态。底部按使用目的分组，关系入口展示当前事项与已有往来；完整人物志放入公司档案。

底部“保存工作”直接写入已有完整存档。顶部显示最后保存章节与北京时间，并对当前状态、选择记录、章节变化提示未保存；读取入口位于系统面板。保存只允许在已完成的章节节点，待确认结果及互动流程不能覆盖存档。

结局画卷：story/ending-review.js维护64项判词与实际当轮评价；assets/endings/为六幅完整插画，ui/ending-review.css为结局与卷宗样式。结算快照独立保存于dragon_ending_reviews，回看不调用解锁或修改游戏状态；无历史快照只展示通用收集条件。

中央会议场景使用既有独立立绘、姓名与职能；电话改为线上消息场景，未知私人联系人只显示匿名标识。右侧看板读取实际项目进度、可用现金和已核查质量，不把协议金额当成现金。个人负荷低于30有预警；悬停或键盘聚焦只展示消耗预估，最终数值以既有结算为准。

HR入职沿用单一CharacterCreatorV2入口与30张完整模板。五步包装为履历提交、工牌照片、能力核验、经历申报、签字入职；不恢复配饰/妆容图层。档案库仍使用v17.2独立收集与迁移规则。

`office-workspace.css`和`office-workspace.js`是界面源码，`node tools/sync-campaign.cjs`会在同步主线后自动嵌入它们。运行脚本位于同一内联游戏脚本末尾，发布页不依赖外部JS/CSS请求；重复同步应保持文件一致。

界面包装不改变项目、关系、晋升、结局、成就及资源规则。工具栏保护结果确认、限时会议、额外交付与私人互动；未完成流程不能经工具栏回到新章节或保存半成品状态。已有互动仍使用自身返回/继续按钮。

验证：`node tests/office-ui.cjs`检查真实浏览器三种布局、中央列优先、分类入口、只读窗口、个人消耗虚影、工牌、存档、在线消息、未知联系人的头像和待确认结果保护。`campaign-browser.cjs`继续验证实际18章与EOP2存档；`creator-v2.cjs`验证30模板/27NPC、迁移及手机布局；`collection-paths.cjs`验证全部64记录和108成就的真实路径与干净重放。

横向事件攻略作为独立交付，不加载到游戏。日程与纪要展示实际开发节点和记录；本次没有新增日常排班资源或改变已验证的选择规则。
